## 1. 定位（最初那几句话）

**A 级**——「`.ambr` 不是必须」：这条用户判断被规格原样回应并认同。

> 📌 认同你的判断：**`.ambr` 不是必须**，定位 = sml 文档的持久化/传输/惰性信封，恰好覆盖
> 「protobuf 场景优化 + 必要时 zstd」。
> ——`docs/amberice-smldb-spec.md:736`（§12.4）

**B 级**——当时写下的定位正文：

- 「二进制**不是必须**。它本质是：**把 protobuf 场景的优化（体积 / lazy / 随机访问）做成 sml
  文档原生的、无需 schema、无需 codegen 的一层**，可叠加 zstd 帧（必要时）。」——`spec:681-682`
- 文件后缀分工：「`.smld` — sml 文本（人类可读的源/文档）」「`.ambr` — sml 的二进制衍生
  （随机访问 / DB BLOB / NoSQL 传输载荷候选之一）」「`.sml` — 通用文本兜底」；
  并注明「`.smld`/`.ambr` 分工已确认」——`spec:21-25`
- 触发条件（做不做）：「出现持久化/重复读需求、内存受限目标、或批量传输；否则暂停」——`spec:739`
- 明确不做：「不把它做成通用 schema 互换格式（那是 protobuf 的地盘），不自造通用 value 二进制」——`spec:740`
- 产品取向：「**默认不暴露数据库特点**」「提供 sml-style（或 amberice）的 NoSQL」——`spec:751-756`
  （同一节 L753 给出 UX 铁律：「操作好上手，同时功能强大」）
- 「核心是让用户永远看不到数据库。四层下潜，用多少学多少。」——`spec:780`
  ⚠️ 该句自带注脚「原话 AI 留给后人」⇒ **是设计会话里 AI 的说法，不是用户原话**，别误引。

## 2. 格式（最初的字节层设想）

**B 级**——`spec §3` 当时的布局（后来被 T0/T1 的实施细节替换，**看方向别看字段**）：

```
[Header] magic "AMBR" | version | flags | root_offset
[StrTab] count + (len:varint, bytes)*        全局字符串表，去重
```

同节六条取舍（`spec §12.3`，原文逐条）：

| 决策 | 取舍理由（原文摘要） |
|---|---|
| magic `"AMBR"` + version + flags（明码 LE） | 固定 LE 牺牲 BE 直接读，换跨平台确定性 |
| 不内带自定界（无长度帧头） | 文档边界靠容器告知（单文件 / DB BLOB 长度 / zstd 帧） |
| 键序决定性（按键排序写） | 换确定性字节 + 缓存 / diff / 去重；代价≈0 |
| Float 保留 raw（`has_raw` flag） | 保 P3 原文逐字还原 |
| 未知 tag 容忍 | 靠 `subtree_sz` 跳过未知子树，向前兼容 |
| 标签 interning 分两层 | 内存=封闭词表，`.ambr`=strtab 偏移，职责不混 |

**B 级**——体积账（`spec:173-183`，2 MB / 52,000 节点实测）：

```
protobuf wire 3317 K / protobuf+zstd 690 K / .ambr 裸 867 K / .ambr+zstd -3 540 K
zstd -3 是甜点（-19 只再省 28 K）；训练字典无收益（534 vs 540 K）
```

**B 级**——冷热分野（`spec:192-200`）：冷数据 `mmap` 不压缩（干净页由内核丢弃，等于 OS 免费压缩），
传输走 zstd 帧；`smldb` = SQLite BLOB **存原文、绝不拆行**；fsync 是真正的悬崖。
