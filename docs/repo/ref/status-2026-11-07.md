## 七、随机访问与流式（已支持）

| 能力 | 入口 |
|---|---|
| 随机访问 | `Store::open` / `open_unverified` / `subtree_bytes` / `get_with_stats` / `history_at` |
| 零拷贝取子树 | `Store::subtree_bytes(path)` 返回 `&'a [u8]`，不物化整棵树 |
| mmap | `mmap::open(path)` |
| 流式写入 | `Writer<W: io::Write>` / `pack_from_readers` |
| 段内定位 | 不存逐段偏移，按 `len` 走表（§19.1）；`Store` 用它做随机跳转 |

**不是缺口的**：随机访问、零拷贝子树、流式写入、mmap。

**真正的边界**：

- 高频读写的小数据（canonical 每次全量重算）
- 单文件内**任意字节偏移**的 mmap（段边界可跳，段内是完整解析）
- 纯流式**读取**（`load` 要完整字节；`Store` 需要 mmap 文件，但不需要解全树）

## 八、amberice 的用途

| 场景 | 用什么能力 |
|---|---|
| 发布产物签名 | 层链 + Ed25519，`sign` / `verify` / `tree` |
| 可增量更新的配置包 | 分层追加 `append`，不重写旧字节 |
| 多语言共享数据 | 五端解码器 + C#/Go/Java/Python/Ruby 绑定 |
| 加密载荷 | `dump_encrypted`（AES-256-GCM）+ 段级压缩 |
| 嵌入式配置 | C99 解码器，零依赖 |
| CI 归档 | `pack --zstd` / `unpack` |
| 审计链 | 每层带作者签名，`tree` 看层链 |
| 数据库底座 | 段表 + 随机访问 + 分层，为 `smldb`（I-18）准备 |

**定位纪律**：`.ambr` 是基座，需要就做**附属 crate**，不往核心里塞场景。
目前只有 CLI 与库，没有开箱即用的上层应用。
