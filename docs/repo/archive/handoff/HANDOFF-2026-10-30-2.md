### 1.3 Rust 先行：把 `35` 从 DIVERGE 收成 AGREE

`35`（只含 `?`）暴露的真缺口：**Rust 与 Lua 不拒绝粘连式 `?`**（`str?` 被当类型名 ⇒ 报

## 4. 环境坑（本轮新增 4 条，均实测）

- **`CARGO_TARGET_DIR` 全局指向仓库外的共享构建缓存目录**（占位表示，真值见本地
  `tools/.private_patterns` 与 `.git/info/exclude`）⇒ 多个 worktree 并发构建互抢产物，
  报 `LNK1104: 无法打开 sml.dll`。**每个 worktree 必须设隔离 target**（如 `<wt>/rust/target_iso`）。
- **本机 `cargo test --workspace` 跑不了**：`swsml` 包内 lib 与 cdylib 同名（都产出 `sml.dll`），
  MSVC 链接器必冲突 ⇒ 只能按 crate 跑，或 `cargo test -p swsml --test <名字>`（指定测试目标可绕过）。
  **副作用：本地无法复现 CI 的全量测试**，CI（Linux）不受影响。
- **`git commit -m "..."` 在本机会报 `fatal: /: '/' is outside repository`**（消息里含 `/` 与引号时）。
  改用 `git commit -F <文件>`；写文件用 `[System.IO.File]::WriteAllText`（默认 UTF-8 无 BOM），
  ⚠️ 别用 `Set-Content -Encoding UTF8`（会加 BOM，把提交标题变成 `\ufefffix(...)`）。
- **PowerShell AMSI `AccessViolationException` 偶发崩溃**（承前，本轮又命中一次）⇒ 关键命令改走
  `cmd /c` 或拆成多条简单命令。
- **conformance 的 Rust 端用哪个二进制**：改过 Rust 后**必须重新构建** `smltools` 并显式设
  `SMLTOOLS`，否则测的是旧实现（会给出假绿/假红）。
