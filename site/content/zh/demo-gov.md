# SML × 政务数据交换 { ❄ }

政务数据有三个老大难，SML 逐一化解：

| 痛点 | 后果 | SML 解法 |
|---|---|---|
| 18 位证件号 / 信用代码被当数字 | JSON 浮点吞精度：`330106201503071234` → `...071200` | 标识符一律字符串，原样保真 |
| 字段拼错静默通过 | `prot` 与 `port` 混进同一份配置 | `strict` 契约当场拦截 |
| 多部门配置复制粘贴 | 改一处漏五处 | `@base` 片段一处定义、处处展开 |
